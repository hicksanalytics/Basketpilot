Historical intelligence

Track prices over time.

Price-history collection

In the cloud database, a price observation will include the retailer, store, product, quantity, collection channel, timestamp, and data source. The preview deliberately has no fabricated historical series.

Real multi-date trends require observations taken on different days. Source-specific histories remain distinct.

Current project infrastructure

Supabase development database created separately. Price history access is private by default; collection scheduling is disabled. This page has no database credentials.
