Use the retailer’s named item number and package quantity as evidence. A product page URL can carry a different ID. Preserve the exact receipt code and verify how it maps to the retailer’s catalog before adding it to the allowlist. Record the warehouse or club ID as shown by the retailer and confirm the receipt format separately. The current parser extracts the Sam’s Club number from its register header. Costco store entry is manual.

Leave package barcodes unset until an independent source ties the barcode to the exact sale package. A bottle barcode, case barcode, and pallet item number can identify different units. A personal barcode link only applies to the shopper’s private history.

The retailer evidence identifies products and locations. The contributing receipt supplies the reported amount, date, and location for the purchase. Label community results as shopper-reported historical prices. The evidence set contains no retailer prices or customer receipt records and is not loaded as a catalog seed.
